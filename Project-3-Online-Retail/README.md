# Online Retail Sales Analysis

## Overview
Analysis of e-commerce transaction data to identify revenue trends, top-performing products, and customer purchasing patterns.

## Problem Statement
An online retailer needed visibility into:
- Which products and categories drive the most revenue
- How sales trend over time
- Customer purchasing behavior and order patterns

## Data Source
- **Dataset:** Online Retail II (UCI Machine Learning Repository)
- **Original size:** Transactions from a UK-based online retailer, December 2009 – December 2011
- **Portfolio slice used:** January–May 2010 (171,834 transactions) — trimmed from the full multi-year file to keep the workbook fast and manageable in Excel. The same approach and formulas scale to the full dataset.
- **Columns:** Invoice, StockCode, Description, Quantity, InvoiceDate, Price, Customer ID, Country
